⌨️ Commands

Prefix: ! (+ !! also works) — type !help in Discord too.

!tier show

Show the full tier list embed.

!tier add S PlayerName

Add a player to a tier.

!tier remove S PlayerName

Remove a player from a tier.

!tier create SS

Create a brand new tier.

!tier delete SS

Delete a tier and its players.

!tier emoji S 👑

Set a custom emoji shown before the tier. Use clear to reset.

!tier setname My List

Rename the tier list.

!tier reset

Clear all players (keeps tiers).

!ai your question

Ask the AI (remembers last ~4 exchanges per server).

!ai forget

Erase your chat memory on this server.

!ai coding auto|on|off

Coding agent mode (default auto: files only when needed).

!files / !get <path>

List / download coding-agent workspace files.

!!connect status

Show AI mode for this server.

!!connect login [openrouter|google|huggingface|github]

Keyless login, no API key needed.

!!connect auth <CODE>

Unlock AI with the owner code.

!!connect api <URL> <KEY> [model]

Custom OpenAI-compatible endpoint (mods).

!!connect free

Back to free AI (mods).

/join <8-digit-code>

Join with a dashboard code (admin codes grant management too).

!ping

Check bot latency.

!8ball Will I win?

Magic 8-ball answers.

!roll 100

Roll a dice up to N.

!joke

Random joke.

!say hello

Bot echoes your text.

!avatar @user

Show someone's avatar.

!userinfo @user

Info about a user.

!serverinfo

Info about the server.

!clear 10

Bulk delete messages (mods only).
